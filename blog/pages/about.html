Hello, I'm Yopa, a structural engineer with more than 20 years in bridge design, including project work in the Middle East. macroBIM Engineering is where I write down the things I explain to younger engineers and students again and again: how bridge and structural elements are sized, why the formulas look the way they do, and how to check a result by hand before trusting software.

What you will find here

  • Bridge components and standard shapes — for example AASHTO and PCI girders, with dimensions, section properties and downloadable CAD outlines.
  • Structural analysis and mechanics of materials — trusses, Mohr's circle, energy methods, buckling and similar topics, explained with worked examples.
  • Design code formulas — material properties and checks from ACI 318, AASHTO LRFD and Eurocode, compared side by side.
  • Interactive tools — small calculators, quizzes and drawing tools that run directly in your browser, so you can try your own numbers.

How the articles are made

Every worked example uses numbers I set up myself, and every calculator on this blog is checked against hand calculations or published reference values before it goes online. Where a post quotes a design code, it names the code and the clause so you can look it up yourself. When something is my engineering judgment rather than a code requirement, I say so.

I also build browser-based design and drafting tools under the name macroBIM. Some posts use the same calculation engines, rewritten so they run inside the article.
