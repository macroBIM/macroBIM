Hwaseong Fortress in Suwon, Korea, is one of the best-documented fortifications of its age. A complete construction report, the Hwaseong Seongyeok Uigwe, was printed in 1801, a few years after the walls went up. I am a bridge engineer, and I wanted to see how one of its gates goes together, stone by stone. So I modeled the Hwaseomun Gate (the west gate) in three.js and let the blocks fall into place one course at a time.

This post shows what Hwaseomun is made of, which drawings I used, the interactive model you can rotate and rebuild, and how the animation and lighting work. The model is still rough. The stone layout is regular and the roof is simplified, and I say exactly where below.

Quick facts
• Hwaseong Fortress: built 1794–1796 under King Jeongjo of the Joseon dynasty, about 5.7 km around, UNESCO World Heritage Site since 1997
• Hwaseomun: the west gate, completed in 1796, designated a Treasure of Korea
• This model: 1,412 blocks, dimensions estimated from a 1999 measured survey report, shape checked against the 1801 Uigwe drawing

❝What is Hwaseomun Gate made of?

A Korean fortress gate is a stack of distinct parts, and each has its own name. The Korean terms are worth knowing because you will see them on every sign at the site.

PartKoreanWhat it isAt Hwaseomun
Stone platform육축 (yukchuk)The masonry base that carries the gate buildingDressed granite laid in courses; most of the stone in the model
Arch홍예 (hongye)A semicircular arch of wedge-shaped stones; a gate with one is a hongyemunThe single passage through the platform
Half-moon enclosure옹성 (ongseong)A second, smaller wall wrapped around the outside of the gateBrick, half-moon shaped, open on one side
Parapet여장 (yeojang)The low crenellated wall on top, for cover and firingOn the platform and along the enclosure
Gate pavilion문루 (mullu)The timber building on top of the platformColumns, beams, bracket sets and a tiled hip-and-gable roof

The enclosure keeps attackers from reaching the gate head-on. At Hwaseomun it curls around the front like a half moon and leaves one side open, so anyone coming in has to turn.

❝Interactive 3D model of Hwaseomun Gate

Blocks are released one at a time and fall 14 m into place. Drag to rotate. Rebuild starts again from an empty site, Slower and Faster halve or double the rate (20 blocks per second to start), and Show finished skips the animation.

❝Build order: one course at a time

All 1,412 blocks are sorted by height. Inside a course they go left to right, so the platform, the enclosure and the wall stubs rise together, course by course. The parapets go on last, and then the pavilion columns, beams and roof. The rubble core behind the facing stones grows with the courses, so you never see an empty box.

❝Blocks by part

Almost half of the blocks, 670, are bricks in the half-moon enclosure: each brick is small (0.6 m × 0.36 m) and they wrap around the curve in 13 courses. The platform uses large granite blocks (1.25–1.7 m long), so it needs only 395.

❝How it is built in three.js

Stones that share a size and material are drawn as one InstancedMesh. Drawing 1,400 separate meshes would stutter, but grouped this way the scene needs only a few dozen draw calls. The falling animation only changes each instance's matrix.

● ● ●  JavaScript
// Stones with the same shape and material share one InstancedMesh
const im = new THREE.InstancedMesh(stoneGeometry, graniteMaterial, stones.length);
im.castShadow = im.receiveShadow = true;
scene.add(im);

// Lay them like a mason: bottom course first, left to right inside a course
stones.sort((a, b) => a.y - b.y || a.x - b.x);

const DROP = 14, FALL = 1.6;           // each stone falls 14 m in 1.6 s
const dummy = new THREE.Object3D();
function place(clock, rate) {          // rate = stones released per second
  stones.forEach((s, i) => {
    const p = Math.min(1, Math.max(0, (clock * rate - i) / (rate * FALL)));
    const fall = p < 0.8 ? (p / 0.8) ** 2 : 1 - Math.sin((p - 0.8) / 0.2 * Math.PI) * 0.04;
    dummy.position.set(s.x, s.y + (1 - fall) * DROP, s.z);   // drop, then a tiny settle
    dummy.rotation.set(0, s.ry, 0);
    dummy.scale.setScalar(p > 0 ? 1 : 0);                     // not its turn yet: hidden
    dummy.updateMatrix();
    im.setMatrixAt(i, dummy.matrix);
  });
  im.instanceMatrix.needsUpdate = true;
}
