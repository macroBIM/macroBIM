# MOTION 실증 하네스

`../MOTION.md` 설계안이 딛고 선 **가정 하나**를 실제로 확인하는 코드다.

> 형상을 다시 만들지 않고, 부재 그룹의 행렬만 갈아끼워도 모델이 움직이는가.

**엔진 기능이 아니다.** `plate_builder_test.js` 는 이 폴더 때문에 바뀌지 않는다.
`MOTION` 입력체계가 실제로 구현되면 이 하네스는 그 회귀 테스트가 된다.

## 왜 되는가

`buildInstance` 는 부재 인스턴스마다 `THREE.Group` 을 하나 만들고, 그 안의 메시에
`matrixAutoUpdate = false` 와 최종 월드 행렬을 박아 둔다. 그래서 **Group 자신의
행렬 자리는 쓰이지 않은 채 비어 있고**, 거기에 4×4 를 써 넣으면 그 부재에 대한
월드 변환이 된다. polybool 절단도, 압출도 다시 일어나지 않는다.

엔진에 필요한 수정은 **한 줄** — 만들어 둔 인스턴스 목록을 밖으로 내보내는 것뿐이다.
그 한 줄을 엔진 파일에 넣어 두는 대신 `patch.js` 가 매번 새로 찍어낸다. 370 KB 짜리
사본을 저장소에 두면 엔진이 한 번만 바뀌어도 곧바로 어긋나기 때문이다.

## 돌리기

```bash
npm i                      # playwright-core · three · polybooljs · exceljs
node patch.js              # plate_builder_test.js -> _engine.js (+1줄)
node verify.js             # 63개 자세 불변식 검사. 실패하면 종료코드 1
node shoot.js && ./assemble.sh   # 크레인 동작 영상 -> crane.webm
```

Chromium 은 `/opt/pw-browsers/chromium` 을 쓴다(`CHROMIUM` 으로 바꿀 수 있다).
`_engine.js` · `node_modules/` · `frames/` · `crane.webm` 은 전부 커밋하지 않는다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `patch.js` | 엔진에서 `_engine.js` 를 찍어낸다. 삽입 지점이 사라지면 **조용히 넘어가지 않고 멈춘다** |
| `page.html` | 하네스. 자세를 먹이고(`__motion`), 결과를 재고(`__bboxOf`·`__anchorOf`), 프레임을 뽑는다(`__grab`·`__aim`). **크레인을 모른다** |
| `crane.js` | TOWER 의 운동학. `MOTION.md` 4절의 BODY/JOINT/FIT 행을 손으로 푼 것 |
| `verify.js` | 불변식 검사 + 자세 계산 시간 |
| `shoot.js` | 216 프레임 촬영 (약 160 초) |
| `assemble.sh` | 프레임 → webm |

## verify.js 가 보는 것

크레인이 크레인으로 남아 있는지를 **네 가지 불변식**으로 본다. 선회 0~180°,
트롤리 ±9 m, 권상 0~11 m 를 조합한 63개 자세 전부에서 성립해야 한다.

| 불변식 | 깨지면 |
|---|---|
| 부재 수가 그대로 | 형상이 다시 만들어졌다 |
| 마스트가 안 움직임 | 안 몰린 것이 딸려 갔다 |
| 로프 상단이 트롤리 안에 | 자식이 부모를 놓쳤다 |
| 로프 하단이 후크 시브에 | `FIT` 이 한쪽만 잡았다 |
| 지브 끝단이 이론 회전 위치에 | 선회가 회전이 아니다 |

현재 전부 **0.000000 mm**, 자세 하나 계산에 **2.03 ms**(575 부재, 초당 493회).

## 측정에 대한 경고 — 두 번 걸려 넘어졌다

**렌더된 프레임을 눈으로 보고 판단하지 말 것.** 카메라 팬과 같은 방향의 선회는
화면상 구분이 안 되고, Ø26 로프는 몇 픽셀이다. 이걸로 한 번 "안 돌았다"고
잘못 읽었다.

**회전 검사에 바운딩박스 중심을 쓰지 말 것.** 월드축 AABB 는 회전에 대해 등변이
아니다 — 30° 돌린 물체의 상자 중심은 물체 자신보다 더 움직인다. 이것 때문에
멀쩡한 회전에 193 mm 오차가 찍혔다. 부재 메시 월드행렬의 이동성분, 즉 **부재 위의
실제 점**을 witness 로 써야 한다. `__anchorOf` 가 그것이다.
