# PLATE3D — DIMSTYLE (도면 치수 스타일 기준값)

도면에 치수·문자를 넣을 때 쓰는 **기준 스타일**. 여기 적힌 숫자는 전부 **축척 1 기준,
즉 출력된 종이 위에서의 mm** 다. 실제 CAD 값은 축척분모를 곱해서 얻는다.

```
CAD 값 = 기준값 × 축척분모          (1:50 이면 × 50)
```

문자 높이도 같은 규칙이다 — `CAD 문자 높이 = 출력 문자 높이 × 축척분모`.

엔진에서는 `DIMSTYLE` 상수와 `dimStyle(scale)` 함수로 들고 있다.
`plateBuilder.dimStyle(50)` 을 부르면 길이 항목이 전부 50배로 곱해져서 나오고,
선택 항목(`pick`)은 길이가 아니므로 그대로 나온다.

```js
plateBuilder.dimStyle(50).base          // 500
plateBuilder.dimStyle(50).text.dim      // 125
plateBuilder.dimStyleBase.base          // 10   (기준값)
```

## 1. 치수 (Dimension Style)

괄호 안 기호는 스타일 대화상자 미리보기의 A~F 와 같다.

**A 와 B 는 이어지는 두 구간이다.** 같은 거리를 두 번 잰 것이 아니다 —
측정점에서 A 만큼 띄우고, 거기서부터 B 만큼 치수보조선이 뻗는다. 따라서
**구조물에서 치수선까지의 거리는 A + B** 이고, 치수보조선의 길이는 B + D 이다.
(둘 다 10 이므로 B 를 전체 거리로 읽으면 치수선이 보조선 시작점에 겹쳐
보조선이 사라진다 — 실제로 한 번 그렇게 냈다.)

| 기호 | 항목 | 기준값 | 키 | 뜻 |
|---|---|---|---|---|
| **A** | Offset From Origin | **10** | `origin` | 측정점과 치수보조선 시작점 사이 띄움 |
| **B** | Distance From Base to Dim | **10** | `base` | A 가 끝난 지점부터 치수선까지 = 보조선이 뻗는 길이 |
| **C** | Offset From Dim to Dim | **10** | `stack` | 치수선을 여러 단 쌓을 때 단 간격 |
| **D** | Extend Beyond Dim | **1.25** | `extend` | 치수보조선이 치수선을 넘어 나가는 길이 |
| **E** | Arrow Size | **1.1** | `arrow` | 화살표(여기서는 점) 크기 |
| **F** | Text Offset From Dim | **0.5** | `textGap` | 문자와 치수선 사이 띄움 |

AutoCAD 시스템 변수로는 A=`DIMEXO`, C=`DIMDLI`, D=`DIMEXE`, E=`DIMASZ`,
F=`DIMGAP` 이다. B 에 해당하는 변수는 없다 — AutoCAD 는 치수선 위치를 사용자가
찍는 값으로 두기 때문이다. 여기서는 스타일이 정한다.

> **D 는 반드시 E/2 보다 커야 한다.** 점(dot) 화살표는 치수선 양쪽으로 E/2 를
> 덮으므로, D 가 그보다 작으면 튀어나온 부분이 통째로 점 밑에 들어가 보이지 않는다.
> 대화상자의 원래 값은 D=0.5 였는데 E=1.1 이라 E/2=0.55 — 항상 가려졌다.
> 그래서 D 만 AutoCAD 기본값인 **1.25** 로 올렸다 (여유 0.7mm).

### 1-1. 지시선 (대화상자에 없는 값)

**치수선과 지시선은 화살표가 다르다.** 치수선 끝은 **점** — "여기서 측정이 끝난다"는
표시다. 지시선 끝은 **속이 찬 삼각형** — "이것"이라고 가리키는 것이므로 뾰족해야 한다.

| 항목 | 기준값 | 키 | 뜻 |
|---|---|---|---|
| 지시선 화살표 길이 | **2.5** | `leadArrow` | 밑변은 길이의 1/3 (통상 3:1) |
| 지시선 사선 길이 | **6.7** | `leadRun` | 45° 로 빠져나가는 다리. 이 뒤에 수평 어깨가 붙는다 |

E(1.1)를 그대로 삼각형 길이로 쓰면 점처럼 보여서 안 보인다 — E 는 **점의 지름**으로
등록된 값이기 때문이다. 그래서 지시선 화살표는 AutoCAD 기본값 `DIMASZ = 2.5` 를 따로 쓴다.

지시선이 여러 개면 순서대로 `leadRun × 0.9` 씩 더 길게 빠져서 각자 자기 어깨에 앉는다.
**구멍처럼 강재 안에서 출발하는 지시선은 어깨가 부재 밖으로 나갈 때까지 다리를 늘린다** —
자기가 뚫린 판 위에 지름이 적히면 찾아 읽어야 한다. 이때도 단계별 어긋남(0.9)은
그 위에 **더한다**. 둘 중 큰 값을 쓰면 두 지시선의 어깨 높이가 같아져 숫자가 겹친다.

### 1-2. 얇은 것의 치수 (웹·플랜지 두께)

두께는 **측정값이지 주기가 아니다.** 그러므로 지시선이 아니라 치수선으로 뽑고,
화살표도 점을 그대로 쓴다. 다만 도면 축척에서 두께는 자기 숫자보다 얇으므로
(H-400 을 1:10 으로 그리면 플랜지 13mm, 문자 25mm) **숫자 놓는 자리만 달라진다.**

| 상황 | 처리 |
|---|---|
| 플랜지 두께 | 플랜지 끝단에서 **오른쪽**으로 치수보조선을 빼고, 치수선을 점 바깥으로 조금 더 연장한 뒤 숫자를 **치수선 옆**에 세운다 |
| 웹 두께 | 보조선을 뺄 곳이 없으므로 웹 중심선 자체가 치수선이다. 두 면에 점을 찍고 숫자를 단면 **밖으로 끌고 나간다** |
| 앵글 다리 두께 | 루트 지시선이 모서리에서 우상향으로 빠지면서 같은 자리를 쓴다. 다리는 위가 열려 있으므로 보조선을 **위로** 빼서 단면 위에서 잰다 |
| 루트 필렛 `r` | 이것만 지시선. 잴 두 면이 없는 모양에 대한 주기이기 때문이다. 오목한 호의 곡률중심 쪽(모서리에서 0.293r)이 유일하게 강재를 되짚지 않는 방향이다 |

## 3. 문자 높이 (출력 기준, mm)

토목 표준도면 실무 관행을 참고하되, **본문 크기는 2.5 로 통일한다.**
치수·주기·부재명이 한 도면 안에서 세 가지 크기로 섞이면 오히려 실수처럼 읽힌다.
제목류만 크기를 달리한다. 관행 범위는 참고로 남겨 둔다 — 법적으로 강제되는
단일 수치는 아니다.

| 용도 | 기준값 | 관행 범위 | 키 |
|---|---|---|---|
| 일반 치수 / 치수선 | **2.5** | 2.5 | `text.dim` |
| 일반 주기 / 설명 | **2.5** | 2.5 ~ 3.5 | `text.note` |
| 부재명 / 주요 표기 | **2.5** | 3.5 | `text.member` |
| 단면명 / 상세명 | **5.0** | 5.0 | `text.section` |
| 주요 제목 | **6.0** | 5 ~ 7 | `text.heading` |
| 도면 제목 | **8.0** | 7 ~ 10 이상 | `text.title` |

`note` 와 `member` 는 값이 같아도 키를 합치지 않는다. 쓰임이 다르고,
나중에 따로 조정할 여지를 남겨 둔다.

축척별로 환산하면 이렇게 된다 (참고용):

| 출력 문자 높이 | 1:10 | 1:20 | 1:50 | 1:100 |
|---|---|---|---|---|
| 2.5 mm | 25 | 50 | 125 | 250 |
| 3.5 mm | 35 | 70 | 175 | 350 |
| 5.0 mm | 50 | 100 | 250 | 500 |
| 7.0 mm | 70 | 140 | 350 | 700 |

> CAD 문자 높이를 직접 입력값으로 관리하지 않고 **출력 문자 높이를 기준으로 관리**하는
> 이유가 이것이다. 축척이 바뀌어도 종이 위 크기는 그대로여야 한다.

## 4. 선택 항목 (`pick`) — 축척과 무관

| 항목 | 값 | 다른 선택지 |
|---|---|---|
| Arrow Heads | **Dot** | Arrow / Circle / Oblique |

| Angle | **00°00'00"** | 00.0° / 00.000° |
| Specification | **Comma** | Dot / None |
| Specification 형식 | **`1 - PL - W x T x L`** | — |
| At | **X** | — |

## 축척을 쓰는 쪽에서 지켜야 할 것

- **길이는 전부 `dimStyle(scale)` 을 거쳐서 쓴다.** 호출부에서 따로 곱하지 않는다.
  기준값이 한 군데 있고 곱셈도 한 군데 있어야 나중에 값을 바꿀 때 새는 곳이 없다.
- `scale` 은 **축척분모**다. 1:50 이면 `50`. 0 이나 음수, 숫자가 아닌 값이 들어오면 1 로 본다.
- `pick` 은 곱하지 않는다. 화살표 모양이나 각도 표기는 길이가 아니다.

## 아직 정하지 않은 것

- Rebar Marking 의 `Length: 100` 이 종이 mm 인지, 아니면 철근 길이 같은 실제 치수인지
  확인이 필요하다. 지금은 다른 항목과 같이 **종이 mm 로 보고 축척을 곱한다**.
- Specification 그룹의 체크박스 5개가 각각 무엇을 켜고 끄는지는 대화상자만으로는
  읽을 수 없어 기록하지 않았다.
