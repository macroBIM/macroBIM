# PLATE3D 엑셀 데이터 입력체계 설계안 (v1)

플레이트 조립 모델을 엑셀로 데이터화하기 위한 시트 구조.
개념: **부재 정의(PLATE) → 빼기 형상(HOLE) → 절단(CUT) → 조립(MODULE) → 배치(ASSY)**.
(구버전 키 PLACE 도 ASSY 의 별칭으로 계속 인식됨)

- 판은 항상 **로컬 XY평면에서 정의** (P1=(0,0), 가로 x, 세로 y, 두께 z)
- 구멍·노치가 있는 판은 "가장 큰 외곽 판 + 잘라낼 부분 subtract" 조합으로 입력
- 배치는 두 방식: **PLANE**(평면+오프셋+각도) / **EDGE**(다른 판의 모서리에 붙이기)

---

## 0. 기본 규약

### 형상 원형: TRAP (사다리꼴) / CIRC (원형)
사다리꼴 파라미터 4개로 삼각형·사각형·사다리꼴을 모두 표현한다.

```
      OF      TW
      ├──┤├──────┤
      P4────────P3      ─┬─
     /            \      │ H
    /              \     │
   P1──────────────P2   ─┴─
   ├──────  B  ──────┤
```

| 파라미터 | 의미 | 비고 |
|---|---|---|
| B  | 밑변 길이 | |
| TW | 윗변 길이 | TW = B → 직사각형, TW = 0 → 삼각형 |
| H  | 높이 | |
| OF | 윗변 좌측단의 수평 오프셋 | 생략 시 (B−TW)/2 = 등변 사다리꼴 |
| THK | 두께 | |
| D | 직경 | SHAPE=CIRC 일 때만 |

### 점·변 이름 (자동 부여) — 9점 체계

점 이름은 **t/m/b (top/middle/bottom) × l/c/r (left/centre/right)** 조합. 변은 `e` 접두사.

```
   tl ───── tc ───── tr      ← et (top)     et = {tl, tc, tr}
    │                │                        eb = {bl, bc, br}
   ml       mc       mr      el (left)        el = {tl, ml, bl}
    │                │       er (right)       er = {tr, mr, br}
   bl ───── bc ───── br      ← eb (bot)       (꼭짓점은 이웃 변과 공유)
```

| 점 | 위치 |
|---|---|
| tl, tr, bl, br | 실제 외곽선의 꼭짓점 |
| tc, bc, ml, mr | 각 변의 중점 (실제 외곽선 위) — 사다리꼴이면 ml/mr은 **빗변의 중점** |
| mc | 도심 |

**판의 로컬 원점 = PLATE/HOLE 행에서 고른 BASE.pt** 이고, 그 점이 (0,0)이 된다.
비워두면 판은 **bc**(하단 중앙), 원형(CIRC)과 HOLE은 **mc**(중심)가 기본.
두께는 이 면을 기준으로 좌우 절반씩(−THK/2 ~ +THK/2) 붙는다.

부속 규칙:
- **실제 외곽선 기준** (bbox 아님) — 오프셋 사다리꼴의 tl은 실제 꼭짓점 (OF, H), tc는 실제 윗변 중점. 판 밖 허공에 점이 생기지 않는다.
- **삼각형(TW=0)**: tl = tc = tr 이 꼭짓점 한 점으로 겹침 (허용). 단 EDGE 방식으로 et 에 붙이는 입력은 에러 처리.
- **로컬 방향 고정**: top/left 등의 방향은 XY평면에 그린 정의 시점 기준. 참조 시에는 배치·회전·MIRROR 적용 후의 세계 좌표를 반환.
- **CUT 무관**: 점은 절단 전 외곽 기준으로 고정 — 노치로 잘려나가도 bl 위치는 유지 (예측 가능, 절단 변경에 조립이 안 깨짐).
- **원형판(CIRC)**: 점은 **5개뿐** — mc + 원주 4분원점 tc / ml / mr / bc (변·꼭짓점 없음). 모서리 이름(tl 등)을 쓰면 tc/bc로 대체된다.
- **예전 표기 호환**: `pbl` `pcc` `plm` `prm` 처럼 p를 붙인 이름과 `lm` `cc` `rm` 도 계속 인식된다 (각각 bl, mc, ml, mr).

## 1. PLATE 시트 — 부재 정의 (부품 라이브러리)

**블록 헤더 방식**: `#`로 시작하는 헤더 행이 아래 데이터 행들의 열 구성을 결정한다.
한 시트에 여러 블록을 섞어 쓸 수 있고, 헤더의 열 이름으로 형상이 자동 판별된다.

```
(사다리꼴)  # PLATE | ID | MAT | THK | TRAP | BASE.pt | WB | WT | H | OFF_T
(사각형)    # PLATE | ID | MAT | THK | RECT | BASE.pt | B | H
(원형)      # PLATE | ID | MAT | THK | CIRC | BASE.pt | D
(빼기형상)  # HOLE  | ID | TRAP | BASE.pt | WB | WT | H | OFF_T
            # HOLE  | ID | RECT | BASE.pt | B | H
            # HOLE  | ID | CIRC | BASE.pt | D
```
(도형 키워드 없는 예전 열 구성 `ID | WT | WB | H | OFF_T | OFF_B | THK | MAT` 도 계속 읽는다)

| 열 | 의미 | 비고 |
|---|---|---|
| WT | 윗변 폭 | WT = 0 → 삼각형 |
| WB | 밑변 폭 | |
| H | 높이 | |
| OFF_T | 윗변 좌측단 수평 오프셋 | 생략 = 0 |
| OFF_B | 밑변 좌측단 수평 오프셋 | 생략 = 0 |
| B | 사각형 폭 | 사각형 블록 전용 |
| D | 직경 | 원형 블록 전용 |
| THK | 두께 | 생략 = 10. **HOLE에는 없음** |
| MAT | 재질 | 표시용. **HOLE에는 없음** |
| BASE.pt | 이 형상의 원점이 될 점 | 9점 중 하나. 생략 = PLATE는 bc, CIRC·HOLE은 mc |

```
      OFF_T    WT
      ├───┤├──────┤
        tl ─────── tr     ─┬─
       /            \      │ H
      bl ─────────── br   ─┴─
  ├──┤├───── WB ─────┤
  OFF_B
```

- 수량 열 없음 — ASSY 행 수로 자동 집계.
- 같은 외곽이라도 구멍이 다르면 다른 ID (제작 도면과 동일한 원칙).
- 구버전 단일 헤더(ID/SHAPE/B/TW/H/OF/D/THK/MAT)도 계속 인식됨.

## 2. CUT 시트 — 빼기 형상 (구멍·노치·절단)

**규칙: PLATE에는 절단 전의 가장 큰 판을 입력하고, 잘라낼 부분마다 CUT 1행.**
CUT 형상이 판 안쪽이면 구멍, 외곽선에 걸치면 노치/절단. 판 밖으로 나가도 되며 겹치는 부분만 빠진다. 여러 행이면 순서대로 계속 subtract.

| 열 | 의미 | 입력값 | 예 |
|---|---|---|---|
| PLATE | 대상 부재 | PLATE의 ID | T1 |
| TYPE | 빼기 형상 | CIRC / TRAP / REF | CIRC |
| D | 구멍 직경 | mm (CIRC) | 22 |
| B, TW, H, OF | 사다리꼴 치수 | mm (TRAP) | |
| REF | 형상 차용 | 다른 PLATE ID (TYPE=REF) | |
| U, V | 위치 (부재 로컬, P1 기준) | mm — CIRC는 중심, TRAP은 P1 | 90, 40 |
| ANG | 면내 회전 | 도(°) | 0 |
| NX, PX | 가로 배열: 개수, 피치 | 개, mm (생략 = 1) | 2, 220 |
| NY, PY | 세로 배열: 개수, 피치 | 개, mm | 2, 220 |

예:
| 케이스 | 입력 |
|---|---|
| 볼트구멍 4개 (2×2) | CIRC D22, U90 V40, NX2 PX220, NY2 PY220 |
| 좌하단 노치 50×110 | TRAP 50×50×110, U0 V0 (모서리에 걸침) |
| 우상단 빗면 80×60 | TRAP B80 TW0 H60, U=B V=H, ANG180 (삼각형을 모서리에 대고 빼기) |
| 다른 판 관통 슬롯 | TYPE=REF, REF=슬롯형상 PLATE ID |

## 3. ASSY 시트 — 배치 (조립)

한 행 = 인스턴스 하나. METHOD로 두 방식 중 선택.

### 공통 열
| 열 | 의미 | 입력값 |
|---|---|---|
| NO | 인스턴스 번호 (고유) | 예: S1-1 |
| PLATE | 부재 | PLATE의 ID |
| METHOD | 배치 방식 | PLANE / EDGE |
| MIRROR | 좌우 반전 | 빈칸 / X |
| GROUP | 병합(용접) 그룹 | 문자열 |

### 방법 1 — METHOD=PLANE : 평면 + 오프셋 + 각도
| 열 | 의미 | 입력값 |
|---|---|---|
| PLANE | 기준 평면 | FRONT(정면) / SIDE(측면) / PLAN(수평) |
| OFFSET | 평면에서 법선 방향 거리 | mm (판의 **두께 중앙면** 위치) |
| U, V | 평면 안에서 P1 위치 | mm |
| ANG | 면내 회전 | 도(°) |

평면별 축 대응 (도면 뷰 그대로):
| PLANE | 로컬 x → | 로컬 y → | OFFSET(두께) 방향 |
|---|---|---|---|
| FRONT (정면도) | 월드 X (우) | 월드 Y (상) | 월드 Z (앞) |
| SIDE (측면도) | 월드 Z (깊이) | 월드 Y (상) | 월드 X (우) |
| PLAN (평면도) | 월드 X (우) | 월드 Z (안쪽) | 월드 Y (상) |

### 방법 2 — METHOD=EDGE : 다른 판의 모서리에 붙이기
| 열 | 의미 | 입력값 |
|---|---|---|
| TO | 붙일 대상 인스턴스 | 예: T2-1 (자기보다 위 행만) |
| MY_EDGE | 내 판의 변 | et / eb / el / er |
| TO_EDGE | 대상 판의 변 | et / eb / el / er |
| FOLD | 변을 힌지로 세우는 각도 | 180=같은 평면 이어붙임, 90=직각, 그 외=경사 |
| ALIGN | 변 방향 정렬 | S(시작)/C(중앙)/E(끝), 기본 S |
| SLIDE | 변 방향 추가 밀기 | mm |
| FLUSH | 두께 정합 | OUT(바깥면)/IN(안쪽면)/C(중심), 기본 C |

```
FOLD=180 (이어붙임)          FOLD=90 (직각 세움)
                                    ┌──┐
────────┬────────           ────────┤  │← 내 판
 대상판  │ 내 판              대상판  └──┘
```

### 배치 예 (서포트 브래킷)
| NO | PLATE | METHOD | 입력 | 뜻 |
|---|---|---|---|---|
| T2-1 | T2 | PLANE | PLAN, OFFSET 0, U −125, V −120 | 바닥 수평판 |
| S1-1 | S1 | EDGE | TO T2-1, eb→eb, FOLD 90, FLUSH OUT | 하판 앞변에 세운 전면 측판 |
| S1-2 | S1 | EDGE | TO T2-1, eb→et, FOLD 90, FLUSH OUT, MIRROR X | 후면 측판 |
| B1-1 | B1 | EDGE | TO T2-1, eb→er, FOLD 90, FLUSH OUT | 우측판 |
| T1-1 | T1 | PLANE | PLAN, OFFSET 280, U −175, V −150 | 수평 상판 |
| C2-1 | C2 | PLANE | SIDE, OFFSET −60, U −60, V 290 | 상판 위 기둥판 |

역할 분담: **기준 판(바닥·상판 등)은 PLANE으로 절대 배치, 붙는 판들은 EDGE로 체인 조립.**

## 4. 엑셀 입력 (단일 시트 · 키워드 방식)

한 시트에 키워드 행으로 순차 입력한다. `Load Excel` 버튼 또는 화면에 .xlsx 드래그&드롭.

**시트 이름은 반드시 `input`** — 통합문서에서 모델을 읽어오는 탭은 `input` 하나뿐이다.
계산용 탭, 도면목록, 예전 리비전 사본 등 다른 탭은 몇 개가 있든 건드리지 않는다.
(`input` 탭이 없으면 첫 번째 탭을 대신 읽고 결과 패널에 어느 탭을 읽었는지 알린다.)

**키워드 열은 A열이 아니어도 된다** — 블록 끝을 `END` 행으로 닫으면 **`END`가 놓인 열**이
그 시트의 키워드 열이 된다. 그 **왼쪽 열들은 전부 자유롭게 쓸 수 있다** — 항목 제목, 메모,
값을 뽑아낸 계산식, 또는 그냥 여백. 키워드 열이 빈 행은 통째로 건너뛰므로 왼쪽에 무엇을 적어도
모델에 영향이 없다. `END` 행이 없으면 각 행이 **자기 행의 첫 번째 채워진 칸**을 키워드로 읽으므로,
A열에 메모를 적으면 그게 키워드로 읽혀 버린다 — `END` 행을 넣는 편이 안전하다.
단 **키워드 오른쪽**은 그 키워드의 필드 자리이므로, 메모는 블록 왼쪽이나 `#` 행에 적는다.

**공통 규칙**
- 행 첫 글자가 `#` 또는 `!` 이면 주석 (무시)
- `END` 키워드가 나올 때까지가 유효한 입력
- 대소문자 구분 없음 — 내부에서 대문자로 변환해 처리
- 필요 CDN: `https://cdnjs.cloudflare.com/ajax/libs/exceljs/4.3.0/exceljs.min.js`

| 키워드 | 값 (순서대로) | 설명 |
|---|---|---|
| PLATE | ID, MAT, THK, **TRAP**, BASE.pt, WB, WT, H, OFF_T | 사다리꼴 부재 |
| PLATE | ID, MAT, THK, **RECT**, BASE.pt, B, H | 사각 부재 |
| PLATE | ID, MAT, THK, **CIRC**, BASE.pt, D | 원형 부재 (봉·원판) |
| HOLE | ID, **TRAP**, BASE.pt, WB, WT, H, OFF_T | 재사용할 빼기 형상 |
| HOLE | ID, **RECT**, BASE.pt, B, H | 〃 |
| HOLE | ID, **CIRC**, BASE.pt, D | 〃 |
| SECT | ID, MAT, Length, **TYPE**, BASE.pt, `<값>` | 압연 형강. TYPE = **H / C / L / P / R** (H형강 · 채널 · 앵글 · 강관 · 각관). 값은 **중간 공백 없이 순차 입력**하며 타입마다 목록이 다르다 (아래 표). `r`을 0이나 빈칸으로 두면 그 모서리는 각지게 나온다. 왼쪽 **SECTIONS** 표에 모이고 클릭하면 단면 도면이 열린다(measure 가능). 배치는 BAR와 동일 — Ref.Pt 없음, 시점부 단면 기준 |
| BAR | ID, MAT, Dia, Length | 직선 환봉. 왼쪽 **BARS** 표(ID·직경·길이·재질)에 따로 모이고, 배치는 MODULE/ASSY로 판과 동일. 예전 `ID, Dia, Length` 순서도 인식 |
| CUT | 판ID, L.X, L.Y, **형상ID**, dx, dy, repeat, `dx2`, `dy2`, `repeat2` | 형상ID(HOLE 또는 다른 PLATE)를 그 판에서 빼기. 뒤 3열은 **2번째 배열 축**(생략 가능) |
| **NOTCH** | 부재, from, to, **L.X, L.Y**, 형상ID, dx, dy, repeat, `dx2`, `dy2`, `repeat2` | **길이의 일부만 따내기.** CUT 에 앞의 두 칸(`from` `to`)이 붙은 것이고, 그 두 칸이 전부다 — CUT 은 단면에서 빼므로 형강에 걸면 늘 길이 전체가 잘린다. `L.X` 에는 **좌표 대신 자리 이름**(`wt` `wb` `tc` …)을 적을 수 있고, 그때 `L.Y` 는 **비운다**. 아래 별도 항목 참조 |
| **NOTCH** | 부재, **BY**, 상대판, `여유` | **그 판이 지나간 자리를 비켜서 따내기.** 두 번째 칸이 `BY` 면 이 문법 — 모양을 적는 대신 **비켜야 할 부재를 지목**하면 엔진이 남길 자국을 구한다. 칼은 **PLATE 여야 한다**. 아래 별도 항목 참조 |
| **MODULE** | ID, PLATE/BAR.ID, Ref.Pt, L.X, L.Y, L.Z, PLANE, ROT.X, ROT.Y, ROT.Z, `dx`, `dy`, `dz`, `repeat`, `dx2`, `dy2`, `dz2`, `repeat2` | 모듈에 부재 1개 배치. 뒤 8열은 **CUT과 같은 2축 반복**(생략 가능) — 아래 별도 항목 참조. 판의 Ref.Pt가 **모듈 로컬 (L.X, L.Y, L.Z)** 에 오고, PLANE은 그 판이 놓일 평면, ROT.X/Y/Z는 그 점을 중심으로 한 회전(도). 행마다 모듈 ID 반복 — 같은 ID 행들이 한 모듈로 누적. PART도 별칭 인식 |

### VIEW — 도면 출력을 위한 키워드

> ⚠️ **잠정** — 열 구성이 확정 전이다. 예제 워크북 밖에서 쓰면 나중에 한 번 고쳐야 할 수 있다.

```
VIEW  <모듈ID>  <방향>  [제목]
```

| 칸 | 값 | 비고 |
|---|---|---|
| 모듈ID | MODULE 의 ID | 그 모듈의 부재만 그린다. 시트 어디에 정의돼 있어도 된다 (아래에 있어도 됨) |
| 방향 | `FRONT` / `BACK` / `LEFT` / `RIGHT` / `TOP` / `BOTTOM` | 어느 쪽에서 본 투영인지 |
| 제목 | 자유 문구 | 도면 위에 쓰인다. 비우면 `모듈ID 방향` |

예:

```
VIEW  md.tfo  TOP     TOP FLANGE - FROM ABOVE
VIEW  md.tfi  BOTTOM  TOP FLANGE - FROM BELOW
VIEW  md.wb   LEFT    WEB - SIDE
```

- **축척은 행이 갖지 않는다.** Save DXF 대화상자가 `VIEWS` 줄에서 물어본다.
  어느 모듈을·어디서 보고·뭐라 부를지는 **모델의 성질**이라 시트가 알지만,
  1:10 으로 뽑을지 1:20 으로 뽑을지는 **종이의 성질**이라 뽑는 사람이 안다.
- `VIEW` 행이 **하나도 없으면** 대화상자의 `VIEWS` 줄은 비활성이고, 나오는 DXF 는
  이 기능이 생기기 전과 **완전히 동일**하다. 특정 워크북을 알아보는 코드는 없고,
  판단 기준은 오직 "이 시트에 `VIEW` 행이 있는가" 하나다.
- 한 장을 빼려면 **행 앞에 `#`** — 다른 행을 끄는 방법과 같다.
- 모듈 이름이 틀렸거나 방향이 목록에 없으면 그 행만 오류로 알리고 건너뛴다.
- 부재가 하나도 안 보이는 모듈(전부 숨김)은 도면을 만들지 않는다. 제목만 있고 속이 빈
  틀을 그리느니 아예 안 그리는 쪽이 낫다.
- **은선(뒤에 있는 것)은 아직 안 그린다.** 지목한 모듈의 부재만 나온다.

- **PLATE와 HOLE은 입력 칸이 같아 보여도 서로 다른 것**
  - PLATE = 실물. 질량·색상·IFC·STL이 전부 이 행에서 나온다.
  - HOLE = 빼기용 2D 형상. **두께도 재질도 받지 않는다** — 그래서 구조적으로 실물이 될 수 없고,
    실수로 MODULE에 배치해도 엔진이 걸러낸다. (깊이가 필요해지는 날이 오면 그 값은 HOLE이 아니라
    CUT 행에 붙는다. 같은 Ø22가 어떤 판에서는 관통, 다른 판에서는 부분일 수 있으므로 깊이는
    *형상*이 아니라 *적용*의 성질이다.)
- **도형 키워드(TRAP/RECT/CIRC)는 고정 칸**에 온다. 그래서 뒤따르는 값 개수가 달라도(TRAP 4개,
  RECT 2개, CIRC 1개) 앞쪽 칸이 밀리지 않는다. 예전처럼 값 패턴으로 형상을 추측하지 않으므로
  MAT 칸에 `400` 같은 숫자를 써도 오인되지 않는다.
- **BASE.pt = 그 형상의 원점**. 9점 중 하나를 고르면 그 점이 (0,0)이 된다.
  비우면 PLATE는 `bc`, CIRC와 HOLE은 `mc`.
- **CUT의 L.X / L.Y 는 대상 판의 원점(= 그 판의 BASE.pt)에서 잰다.** 놓이는 형상은
  **자기 BASE.pt** 가 그 자리에 오도록 배치된다.
  예: `HOLE h.M22 CIRC mc 22` + `CUT pl.T1 -110 90 h.M22` = 판 원점에서 왼쪽 110, 위 90에 Ø22 구멍 중심
- **대상 판은 CUT 행보다 먼저** 정의돼 있어야 한다. 형상(HOLE/PLATE)은 시트 어디에 있어도 된다.
- **ID는 PLATE와 HOLE이 같은 공간을 쓴다** — CUT의 형상ID가 둘 다 가리킬 수 있기 때문. 중복되면 오류.
- 예전 CUT 순서도 계속 읽는다:
  `CUT [판ID] [기준점] L.X L.Y dx dy repeat RECT B H | CIRC D | PLATE ID` (형상을 **중심** 기준 배치)
  `CUT [판ID] [기준점] RECT B H L.X L.Y L.ROT dx dy repeat` (형상을 **좌하단** 기준 배치)
  `dx2 dy2 repeat2` 는 **세 형식 모두** 그 형식의 마지막 값 뒤에 붙일 수 있다.
- 예전 PLATE 행(도형 키워드 없음)도 계속 읽는다: `PLATE ID WT WB H OFF_TOP [OFF_B] THK MAT`, `PLATE ID B H THK MAT`
- **dx / dy / repeat = 배열 복제**: repeat는 **추가 복제 개수**(원본 제외 — 0/빈칸이면 1개, 1이면 총 2개), dx·dy는 복제 간격 벡터.
  예: `CUT pl.T1 -110 90 h.M22 0 220 1` = Ø22 구멍이 (−110, 90)과 (−110, 310)에 2개
- **dx2 / dy2 / repeat2 = 2번째 배열 축**(생략 가능): 위에서 만든 **한 줄 전체**를 dx2·dy2 만큼
  옆으로 옮겨 `repeat2` 개 더 만든다. 즉 한 행이 격자를 만든다. 총 개수 = `(repeat+1) × (repeat2+1)`.
  예: `CUT pl.T1 35 85 h.M22 75 0 1 0 -170 1` = 길이방향 75 간격 2개 × 폭방향 170 간격 2줄 = 4개
  - 비워두면 **기존 1차원 반복과 완전히 동일** — 기존 시트는 아무것도 달라지지 않는다.
  - 두 개수 모두 **수식**이어도 되므로, 앞장(PARAM 같은 계산 시트)에서 볼트 개수를 바꾸면
    구멍이 따라온다. **볼트 배열 한 덩어리가 CUT 한 줄**이 되는 것이 이 열의 목적.
  - 조인트 유격처럼 가운데 간격이 다르면 한 행으로는 안 되고 **사분면당 한 행, 총 4행**이면
    개수와 무관하게 어떤 볼트 배열이든 표현된다.
  - `(repeat+1) × (repeat2+1)` 이 **2000** 을 넘으면 2000개까지만 자르고 오류로 알린다
    (한 개마다 불리언 빼기 1회라, 수식이 어긋나면 그대로 멈춰버리기 때문).
- PLANE: **XY(수평)/XZ(정면)/YZ(측면)** — Z-up 기준. Ref.Pt: tl·tc·tr·ml·mc·mr·bl·bc·br (예전 p 접두사 표기도 인식)
- **ASSY도 같은 ID 행이 누적된다** — `ASSY as.comb md.tower ADD 0 0 0` 다음 줄에
  `ASSY as.comb bar.pt3m ADD 1000 1000 0` 을 쓰면 조립체는 **as.comb 하나**이고 그 아래에
  모듈과 봉이 함께 들어간다. 첫 행이 조립체의 기준점을 정하고, 이후 행의 G.X/G.Y/G.Z도
  절대좌표 그대로. **ADD뿐 아니라 MIR/COPY/ROT도 같은 ID면 그 조립체에 누적된다** —
  `ASSY as.a as.a MIR …` 처럼 자기 자신을 참조해 반사시켜 조립체를 완성하는 방식도 쓸 수 있고,
  그 뒤에 `as.a`를 다시 배치하면 **반사본까지 포함한 지금 상태 전체**가 함께 간다.

| TYPE | 값 | 뜻 |
|---|---|---|
| **H** | `h bb bt tw tf1 tf2 r1` | h=전체 높이, bb=하부 플랜지 폭, bt=상부 플랜지 폭, tw=웹 두께, **tf1=하부** 플랜지 두께, **tf2=상부** 플랜지 두께, r1=루트 필렛 (**H는 토 라운딩 없음** — 값 7개) |

| **L** | `a b t1 t2 r1 r2` | a=가로 다리, b=세로 다리, **t1=a 다리 두께**, **t2=b 다리 두께**, r1=루트 필렛(안쪽 모서리), r2=토 라운딩(다리 끝단) |

| **R** | `h b t r` | 각형 강관. h=높이, b=폭, t=관 두께, r=**바깥** 모서리 반지름 (안쪽은 `r − t`, 값 4개) |

- 값의 개수는 타입마다 다르다 — H 7개, C·L 6개, R 4개, P 2개. C와 L은 개수가 같지만 **의미가 다르므로 타입별로 읽는다.** 등변 앵글도 `a b t1 t2`를 모두 적는다 (예: `100 100 10 10`).
- 필렛은 실제 원호로 작도한다 (90°당 8분할, 면적 오차 0.06%). 생략하면 H-400×200×8×13 기준 면적이 약 2.6% 부족해진다.
- **r을 0으로 두거나 비우면 오류 없이 각진 모서리**로 그려진다.
- **SECT 입력값 검증** — 아래를 어기면 그 행은 **오류로 알리고 만들지 않는다** (억지로 고치지 않음).
  치수값이 0 이하이거나 빈칸 / Length가 0 이하 / 플랜지가 h를 넘음 / tw가 플랜지보다 두꺼움 /
  필렛이 웹 순높이·플랜지 내민 길이·다리 길이를 넘음 / 토 라운딩이 플랜지(다리) 두께를 넘음 /
  반지름 음수 / TYPE이 H·C·L·P·R 이 아님 / BASE.pt 이름 오류.
- **SECT에 CUT을 걸면 길이 전체가 잘린다** — 판의 구멍과 의미가 다르니 주의.
  길이의 **일부만** 따내려면 `NOTCH` 를 쓴다 (아래 항목).

### NOTCH — 길이의 일부만 따내기

```
NOTCH  <부재>  <from>  <to>  <L.X>  <L.Y>  <형상ID>   [dx dy repeat] [dx2 dy2 repeat2]
NOTCH  <부재>  BY  <상대판>  [여유]
```

`CUT` 은 **단면**에서 빼기 때문에, 형강에 걸면 늘 **길이 전체**가 잘린다.
`NOTCH` 는 거기에 앞의 두 칸을 더한 것이고, 그 두 칸이 차이의 전부다 —
**어느 구간에서** 뺄지.

**이름이 먼저다.** `L.X` 에는 좌표 대신 **자리 이름**을 적을 수 있고, 그때 `L.Y` 는
비운다. 이게 보통 쓰는 방식이다 — 숫자는 단면이 바뀌면 조용히 틀려지지만,
이름은 따라온다.

| 칸 | 값 | 비고 |
|---|---|---|
| 부재 | `SECT`(또는 `PLATE`·`BAR`) ID | 모양의 정의를 지목한다. 그 부재가 놓인 **모든 자리**가 같이 따인다 |
| from / to | 부재 축을 따라 잰 거리 | **MODULE 행이 놓는 쪽 끝이 0.** `to` 를 비우면 **반대쪽 끝까지**. `to ≤ from` 은 오류 |
| L.X | 자를 자리 — **이름** 또는 좌표 x | 이름이면 `L.Y` 는 **비운다**. 쓸 수 있는 이름은 그 단면이 가진 것뿐이고, 틀리면 **가진 이름을 전부 알려 준다** |
| L.Y | 좌표 y | `L.X` 에 숫자를 적었을 때만 |
| 형상ID | `HOLE` 또는 다른 `PLATE` 의 ID | `CUT` 과 똑같다 |
| dx dy repeat / dx2 dy2 repeat2 | 2축 반복 | `CUT` 과 같은 규칙 (생략 가능) |

**자리 이름** — 9점(`tl tc tr ml mc mr bl bc br`)에 더해, H형강은 두 개를 더 갖는다.

| 이름 | 어디 |
|---|---|
| **`wt`** | 웹이 **윗** 플랜지와 만나는 자리 |
| **`wb`** | 웹이 **아랫** 플랜지와 만나는 자리 |

9점은 바운딩 박스의 네 모서리에서 나오므로 플랜지 면과 한가운데는 짚어도,
**스캘럽이 실제로 들어가는 자리**는 못 짚는다. `wt`·`wb` 가 그 자리다.
H-300 에 `wt` 라고 쓰면 지금은 `135` 를 적은 것과 같지만, H-400 으로 바꾸면
`wt` 는 따라가고 `135` 는 안 따라간다.

**`BY` — 모양 대신 부재를 지목한다**

```
NOTCH  sc.bm1  BY  pl.stf1  5
```

비켜야 할 부재를 지목하면 엔진이 **그 부재가 남길 자국**을 구해서 따낸다.
스티프너·거셋처럼 "저것이 지나가니 여기를 비운다" 가 곧 주문인 자리에 쓴다.

- **칼은 `PLATE` 여야 한다.** 형강은 들어가면서 모양이 바뀌므로(플랜지는 300,
  그 뒤 웹은 10) 노치 하나가 아니다 — 오류로 알린다. 형강으로 자르려면 위의
  앞 문법으로 직접 적는다.
- **칼은 주문한 원판이다** — 그 판에 걸린 `CUT`(스캘럽 등) 전의 외곽선을 쓴다.
  스캘럽은 용접 디테일이지 자리다툼과는 상관이 없다.
- **그 판이 놓인 모든 사본**이 칼이 된다. 스티프너가 웹 양쪽에 두 장 놓이면 한 줄로 족하다.
- **순서가 규칙이다.** 상대판이 이 행보다 **위에서 이미 배치**돼 있어야 한다.
  아직 안 놓인 것을 지목하면 행 번호를 대며 거절한다 — `CUT` 이 위쪽 판을
  지목하는 것과 같은 규칙이다.
- `여유` = 자국을 **칼의 모서리에서** 넓히는 값(mm). 판이 놓인 평면 안의 두 방향
  (폭·길이)으로만 넓히고, **두께 방향으로는 넓히지 않는다** — 부재는 판이 차지한
  만큼을 이미 내주었고, 그보다 더 파는 것은 판 건너편의 강재를 파는 것이다.
  비우면 0. 음수는 오류.
- 자기 자신을 칼로 쓰면 오류.

**따라오는 것들**

- **토막은 단면이 실제로 달라지는 자리에만 생긴다.** 살에 안 닿는 노치는 아무것도
  나누지 않고, 부재 전체를 덮는 노치는 그냥 `CUT` 과 같아진다.
- **부재표에 공제 열이 붙는다** — 무엇이든 하나라도 따였을 때만. 살아 있는 수식이다.
- 부재 도면(옆면도)과 2D 도면·클래시 검사가 모두 따낸 뒤의 모양을 따른다.

<!-- FIT — 위와 같은 이유로 숨겨 둔다. 지우지 않는다.

### FIT — 끝을 상대 부재의 면에 맞춰 자르기

```
FIT  <부재>  <B|E>  <상대부재>  [GAP]
MODULE <모듈ID>  FIT  <부재>  <B|E>  <상대부재>  [GAP]
```

| 칸 | 값 | 비고 |
|---|---|---|
| 부재 | MODULE 로 **2점 배치**된 BAR/SECT | 판은 자를 축이 없어 오류. 복사본은 `s.brc_2` 처럼 번호까지 (맨 이름 = 첫 번째, 알림) |
| B / E | 어느 끝 | **B** = (LX1,LY1,LZ1) 쪽, **E** = (LX2,LY2,LZ2) 쪽 — `OFF_B`/`OFF_E` 와 같은 두 끝. 한 끝에 한 행, 양 끝 다 가능 |
| 상대부재 | **같은 모듈 안**의 판 또는 형강 | 환봉(BAR)은 표면이 곡면이라 맞출 평면이 없다 → 오류 |
| GAP | 루트갭 | **절단면에 직각으로** 잰다. 양수 = 면에서 물러남(`OFF_B` 와 같은 부호). 비우면 0 = 면에 밀착 |

- **어느 면인지는 적지 않는다.** 부재 축을 그 끝 방향으로 연장해 **처음 닿는 면**이 절단면이다. 광선은 부재 **중앙**에서 출발하므로, OFF 가 음수여서 부재가 절점을 지나 상대 안으로 들어가 있어도 바깥 면을 제대로 잡는다.
- **단면 전체가 잘려야 한다.** 단면 외곽선의 **모든 꼭짓점**을 축 방향으로 쏘아 전부 같은 면에 닿는지 확인하고, 하나라도 빗나가거나 다른 면에 닿으면 **오류로 알리고 그 끝은 직각으로 남긴다**. 단면 일부만 걸리는 이음(플랜지가 상대보다 넓어 밖으로 나가는 경우)은 톱질로 연장할지 코핑으로 파낼지가 **디테일 결정**이라 모델이 대신 정할 수 없다.
- **중량은 정확하다** — 단면적 × **도심에서의 축 길이**. 평면 절단이면 길이가 단면 위에서 1차식이라 평균이 도심값과 같다.
- 딸려오는 것들: SECTIONS 길이가 `L1697.06∠` 로 표시되고, **각도가 다르면 다른 부재**로 집계된다. 2D 도면·measure 스냅·클래시 검사가 모두 실제 끝면을 따른다. IFC 는 스윕이 아니라 **brep**(`IFCFACETEDBREP`)으로 나간다.
- 오류로 알리고 그 행을 건너뛰는 경우: 절단면이 축과 거의 나란함 / 양 끝면이 단면 안에서 교차 / 축이 상대에 닿지 않음 / 한 끝을 두 번 자름 / 상대가 같은 모듈에 없음.
- **FIT 을 건 끝의 `OFF` 는 더 이상 끝 위치를 정하지 않는다** — 알림이 뜬다. 물러나게 하려면 `GAP` 을 쓴다.
- **MODULE 의 2축 반복** (`dx dy dz repeat` + `dx2 dy2 dz2 repeat2`, **두 형식 모두**):
  CUT 과 같은 규칙이다. 첫 축을 `repeat` 번 더 밟고, 두 번째 축이 **그 줄 전체**를 옆으로
  `repeat2` 번 더 옮긴다. 총 개수 = `(repeat+1) × (repeat2+1)`, 상한 2000.
  예: `MODULE md.blt bo.M22 (빈칸) 35 50 110 XY 0 0 0  75 0 0 3  0 55 0 2` = 볼트 12개
  (길이방향 75 간격 4개 × 폭방향 55 간격 3줄)
  - 비워두면 **부재 1개** — 기존 시트는 달라지지 않는다.
  - **이게 없으면 부재 개수를 수식이 못 정한다.** 행은 수식으로 만들 수 없으니, 한 줄에
    하나씩 쓰는 시트는 파일을 쓰는 순간 개수가 고정된다. 간격은 앞장에서 바꿔도 개수는 못 바꾼다.
  - 복사본은 **같은 이름을 쓰고 뒤에 번호가 붙는다** (`bo.M22_1`, `bo.M22_2` …).
    그래서 `BASE` 는 번호까지 써야 한다 — 맨 이름만 쓰면 첫 번째를 뜻하고 알림이 뜬다.
  - **좌표 배치 형식에서도 똑같이 쓴다.** 8칸이 `Alpha` 뒤에 붙고, 복사본은 **양 끝점을
    같은 양만큼** 옮긴다 — 방향·길이·양단 OFF 가 그대로 유지된다.
    예: `MODULE md.rail s.brc (빈칸) 0 0 0  0 0 900  0 0 0  1500 0 0 5  0 2400 0 1`
    = 900 높이 기둥 12개(X방향 1500 간격 6개 × Y방향 2400 간격 2줄)
- **부재ID 칸이 비면 그 행은 조용히 건너뛴다** (MODULE·CUT 공통). 앞장에서 끈 행이라는 뜻이다.
  `=IF(조건,"bo.M22","")` 처럼 써서, 최대치만큼 깔아두고 안 쓰는 것만 끄는 데 쓴다.
  오류가 아니므로 알림도 뜨지 않는다.
- **BAR 부재는 Ref.Pt를 비운다.** 봉은 항상 **시점부 원형 중심**이 기준이고, 거기서 그 평면의
  두께 축 방향으로 Length만큼 뻗는다. XY면 +Z, XZ면 −Y, YZ면 +X.
  예: `MODULE md.tower bar.pt3m (빈칸) 0 0 0 XY` = 원점에서 위로 3000mm 서는 봉.
  ASSY에 봉을 직접 놓을 때도 같다 — G.X/G.Y/G.Z가 시점부 중심.
- **MODULE 행 읽는 법**: 「이 판(PLATE.ID)의 이 점(Ref.Pt)을 모듈 좌표 (L.X, L.Y, L.Z)에 놓고, PLANE 평면에 눕히고, 필요하면 그 점을 중심으로 ROT.X/Y/Z만큼 돌려라」
- **MODULE 좌표 배치 행 읽는 법**: 「이 봉/형강을 모듈 좌표 (LX1,LY1,LZ1)에서 (LX2,LY2,LZ2)까지 늘여 놓고, 시작을 OFF_B, 끝을 OFF_E만큼 자르고(음수면 반대로 더 내밀고), 자기 축 둘레로 Alpha만큼 돌려라」
  - PLANE 자리(8번째 칸)가 **평면 이름이면 각도 방식, 숫자면 좌표 방식**이다. LX2/LY2/LZ2 세 칸 중 하나라도 숫자면 좌표 방식으로 읽는다 — 수직 부재는 LX2/LY2가 빈칸이 되기 때문.
  - Ref.Pt는 **축선을 타는 단면 점**이다. 비우면 그 단면의 BASE.pt — 거의 항상 이게 맞다.
  - 절점(작업선 교점) 좌표를 그대로 넣고 OFF로 실제 강재를 맞추는 것이 기본 사용법이다.
    양수 = 절점에서 물러남(클리어런스), 음수 = 절점을 지나 파고듦(겹침·매입).
  - 같은 단면 정의 하나로 길이가 다른 부재를 몇 개든 만들 수 있다. 단 **모듈 안에서 부재 ID는
    달라야** 하므로 `sc.brc_1`, `sc.brc_2` … 로 쓴다.
- **ASSY의 기준점**: 참조 대상이 MODULE이면 그 모듈의 **BASE 점**, 낱장 PLATE면 **bc**(평면은 XY 기준, 필요시 ROT으로 회전), 다른 ASSY면 그 조립체의 **자기 원점**
- **좌표 기준**
  | 명령 | 좌표 칸 | 의미 |
  |---|---|---|
  | ADD | G.X/G.Y/G.Z | **절대** — 참조 대상의 기준점이 이 좌표에 온다 |
  | MIR | G.X/G.Y/G.Z | **절대** — 대칭 평면이 지나는 점 |
  | ROT | C.X/C.Y/C.Z | **절대** — 회전축이 지나는 점 |
  | COPY | d.X/d.Y/d.Z | **상대** — 참조 대상이 놓인 자리에서의 이동량 |

  MIR·ROT·COPY는 모두 참조 대상을 **이미 놓인 자리에서** 반사·회전·이동시킨다.
  repeat는 CUT과 같이 **추가 복사 개수**(원본 제외)이고, ROT의 각도는 누적된다(30°, 60°, 90° …).
- **ID 칸에 쓴 이름은 조립체 이름이고, 어떤 명령이든 그대로 쓴다** — ASSY ID에는 번호가 붙지 않는다.
  **ID 하나 = 조립체 하나 = 왼쪽 목록의 그룹 하나.**
  번호가 붙는 쪽은 **조립체에 들어가는 대상(ref)** 이다. 참조한 ID 뒤에 명령 글자를 붙여 구성원 ID를 만든다:

  | 명령 | 구성원 ID | 비고 |
  |---|---|---|
  | ADD | `ref.A` | 1개만 놓으므로 번호 없음 |
  | MIR | `ref.M` | 〃 |
  | COPY | `ref.C001`, `ref.C002` … | 점 + 3자리, **최대 999** |
  | ROT | `ref.R001`, `ref.R002` … | 〃 |

  예: `ASSY as.comb md.tower ADD` + `ASSY as.comb bar.pt3m ADD` → 그룹 **AS.COMB** 안에
  `MD.TOWER.A`, `BAR.PT3M.A` 두 줄. `ASSY as.comb.cp md.tower COPY 0 800 0 4` → 그룹
  **AS.COMB.CP** 안에 `MD.TOWER.C001` ~ `C004` 네 줄.
  같은 조립체 안에서 같은 대상에 같은 명령을 또 쓰면 번호가 이어진다.
  repeat가 999를 넘으면 999개까지만 만들고 오류로 알린다.
- MIR 결과물도 정상적인 우수좌표계로 만들어진다 — 반사는 판 외형(프로필)에 접어 넣으므로
  STL 면 방향과 IFC 배치가 깨지지 않는다.
- 명령 칸(ADD/MIR/COPY)을 생략하면 ADD로 읽으므로 예전 시트도 그대로 동작한다.
- ASSY는 **중첩 가능** — 먼저 정의한 ASSY를 참조해서 더 큰 조립체를 만들 수 있음 (같은 ID를 여러 번 쓰면 `-2`, `-3` 접미사가 붙어 복수 배치)
- 회전 순서는 X → Y → Z (모듈/글로벌 축 기준)
- **좌표계는 Z-up 우수좌표계** — X 동, Y 북, **Z 위(높이)**. IFC·AutoCAD·Revit·Tekla 와 동일.
  화면·STL·IFC 모두 같은 좌표를 쓴다(변환 없음).

  | PLANE | 판의 로컬 x → | 판의 로컬 y → | 두께(+면) 방향 | 도면 |
  |---|---|---|---|---|
  | `XY` | X | Y | **+Z (위)** | 평면도 |
  | `XZ` | X | **Z (높이)** | −Y | 정면도 |
  | `YZ` | Y | **Z (높이)** | +X | 측면도 |

- **색상 규칙**: PLATE 목록 = 판별 색(모듈 미리보기에서 보임) · MODULE 목록 = 모듈 대표색(조립 화면에서 보임).
  조립(ASSY) 화면에서는 **모듈에 속한 판은 전부 그 모듈의 대표색**으로 칠해지고 판별 색은 무시된다.
  낱장으로 배치한 판은 자기 판 색을 그대로 쓴다.
- **왼쪽 MODULES 목록은 모듈 이름까지만** — 모듈을 클릭하면 열리는 미리보기 창 왼쪽 패널에
  구성 판 목록이 나오고, 판마다 **hide/show 체크 · 색상 · 투명도 · local axes** 를 조작한다.
  숨긴 판은 미리보기의 STL/IFC 출력에서도 빠진다.
- **ASSEMBLY 목록의 모듈 행**: hide/show 체크 · 모듈 대표색 선택 · 투명도 슬라이더
- **local axes 체크**: 미리보기 판 목록의 이름 옆 체크박스(또는 3D 화면의 `local axes`)를 켜면, 그 판의
  **Ref.Pt 위치**에 로컬 좌표축이 그려지고 기준점이 노란 원 + 점 이름(`bc`, `bc+` 등)으로 표시된다.
  두께 방향은 `+Z`(파랑) / `−Z`(회색) 화살표와 라벨로 양쪽 다 표시되어 어느 면이 +인지 바로 보인다.
- **id 체크박스**: 3D 화면과 모듈 미리보기 상단에 있음. 켜면 각 판 위에 이름표가 붙는다 —
  메인 화면은 배치 인스턴스 ID(`AS.A/PL.T1`), 미리보기는 모듈 안의 판 이름(`PL.T1`).
- **`+ / − surface` 체크박스**: 메인 화면의 `+ / − face` 와 같은 기능을 미리보기 헤더에도 추가.
- `id` · `+/− surface` · `measure` 는 **두 창이 각각 독립**으로 동작한다
  (`surface only` 만 두 창이 같은 상태를 공유).
- **plate 2D 창에서도 measure** 가 된다 — 9점·구멍 중심에 스냅되고, 두 점을 클릭하면
  거리와 ΔX·ΔY가 도면 위에 그려진다. 오른쪽 클릭으로 초기화, 드래그는 그대로 팬.
- **원형 구멍은 지름이 자동 표기**된다 — 원에 화살표가 닿는 지시선 + `Ø22`.
- **regen 버튼**: plate 2D 창·module 3D 창 헤더에 있음. 줌·팬·회전한 화면을 처음 열렸을 때의
  시점으로 되돌린다.
- **measure 체크박스**: 3D 화면 상단과 모듈 미리보기 헤더에 있음. 켜면 스냅 가능한 점(판 모서리·
  구멍 중심) 부근에 커서를 가져가면 노란 빈 원으로 표시되며 그 점에 붙는다. 두 점을 클릭하면
  ΔX·ΔY·ΔZ와 직선거리가 표시되고, **오른쪽 클릭으로 선택 초기화**(세 번째 왼쪽 클릭도 새 측정).
  측정 중에도 드래그 회전·오른쪽 드래그 팬은 그대로 동작한다.
- **왼쪽 ASSEMBLY 목록은 ASSY ID 하나에 그룹 하나**이고, 그 안에 **구성원 ID 한 줄씩** 들어간다
  (`AS.COMB.CP` 그룹 → `MD.TOWER.C001` … `C004`). 그룹 체크박스로 조립체 전체를 한 번에 껐다 켤 수
  있고, 각 줄은 자기 구성원만 껐다 켠다. 줄마다 그 안에 든 모듈(또는 낱장 판)의 색이 붙는다.
  다른 ASSY를 통째로 넣은 줄은 여러 모듈이 섞여 있으므로 색 없이 개수(`1 module + 1 part`)만
  표시된다. 판 단위는 MODULE 목록과 미리보기에서 확인.
- **구성원 이름 클릭 = 3D에서 선택 표시** — 그 배치본이 발광하고 외곽선이 청록으로 바뀌며
  바운딩 박스가 쳐진다(다른 부재에 가려져도 보이도록 깊이검사 없음). 목록 줄도 청록으로 강조되고,
  같은 줄을 다시 누르면 해제된다. 똑같이 생긴 사본이 수십 개일 때 **어느 줄이 어느 것인지**
  집어내는 용도다. **미리보기 창은 열리지 않는다** — 모듈 자체를 보려면 위쪽 MODULES 목록에서 연다.
- **그룹 식별 색 + 접기** — **ASSY ID 맨 앞의 원형 ⌄ 아이콘**(글자 크기, 조립체마다 다른 색)이
  접기 버튼이자 그룹 표식이다. **목록에서 그룹을 구분하기 위한 색일 뿐 3D 색과는 무관**하다
  (3D는 모듈/판 색 그대로). 헤더에는 구성원 수가 같이 표시되어 접어 둔 채로도 규모를 알 수 있다.
  **시트를 로드하면 모든 조립체가 접힌 상태로 시작**한다 — 조립체당 한 줄짜리 목차가 되어
  사본이 수십 개인 모델도 한 화면에 들어오고, 필요한 것만 펼쳐 본다. 펼침/접힘 상태는 ID 기준으로
  기억하므로 색을 바꿔 목록이 다시 그려져도 유지되고, 새로 로드하면 다시 전부 접힌다.
- **HOLES 목록** — 왼쪽 패널 맨 위에 `HOLES · PLATES · BARS · SECTIONS` 순으로 나온다.
  HOLE은 빼기 형상이라 색도 중량도 없고, **ID · SIZE · USED**(그 형상을 쓴 CUT 행 수)만 표시한다.
  ID를 누르면 판과 같은 2D 도면이 열려 9점·치수를 확인하고 measure로 잴 수 있다.
  `USED`가 `—`이면 정의만 해 두고 아직 CUT에 쓰지 않은 형상이다.
- **`COORD YUP`** 행을 MODULE/ASSY 보다 위에 한 줄 넣으면, 예전 Y-up 기준으로 작성한 시트를
  그대로 읽는다 (예전 좌표계로 조립한 뒤 한 번만 세워서 배치). 기본값은 `COORD ZUP`.
- 예전 열 순서(`PLANE Ref.Pt L.X L.Y L.ROT OFFSET`, `ASSY 대상ID PLANE …`)도 계속 읽음 — 세 번째 칸이 평면 이름인지로 자동 판별
- **Ref.Pt 뒤에 `+` / `−` 를 붙이면 두께 방향 기준면이 바뀜** (MODULE·POS·BASE·ASSY 모두 동일)

  | 표기 | 기준 | OFFSET이 가리키는 곳 |
  |---|---|---|
  | `bc` (기본) | 두께 중앙 | 판의 중립면 |
  | `bc+` | +면 (로컬 +Z 쪽 면) | 그 면이 OFFSET 위치에 옴 → 판은 OFFSET−THK ~ OFFSET |
  | `bc-` | −면 (로컬 −Z 쪽 면) | 그 면이 OFFSET 위치에 옴 → 판은 OFFSET ~ OFFSET+THK |

  즉 도면에 적힌 **면 치수를 그대로 입력**하면 되고, `±THK/2` 를 손으로 더할 필요가 없다.
  ± 방향(어느 쪽이 +면인지)은 좌측 MODULE 목록의 **local axes 체크박스**나 상단 **+ / − face** 버튼으로 확인.
  예: 두께 20 판을 `XZ bc+ 0 0 0 500` → 판 윗면(+면)이 Y=500, 판은 Y 480~500 차지
- **MODULE 조립 시 ASSY의 Ref.Pt**: 빈칸/`o` = BASE 점 (기본) · 9점 이름(`bc` 등) = 모듈 바운딩박스 점(Z는 중앙, `bc+`/`bc-`면 박스 앞/뒤면) · `판인스턴스.점`(예: `pl.C2_1.tc`, `pl.C2_1.tc+`) = 특정 판의 점 직접 지정
- ID에 `_숫자` 접미사를 붙이면 같은 MODULE/PLATE의 인스턴스로 인식 (예: `md.COL_1`, `md.COL_2` → 모듈 md.COL 2개 배치)
- ID 접두사 관례: `pl.` 판 · `br.` 볼트/봉 · `md.` 모듈
- 모듈 예 (한 행 = 판 1장, 모듈 ID 반복):
```
#MODULE  ID        PLATE.ID  Ref.Pt  L.X  L.Y  L.Z  PLANE  ROT.X ROT.Y ROT.Z
MODULE   md.tower  pl.T1     bc+     140    0    0  XZ
MODULE   md.tower  pl.C1_1   bc        0    0    0  XY
MODULE   md.tower  pl.C1_2   bc        0    0  120  XY
MODULE   md.tower  pl.C2_1   bc      -60    0   60  YZ
MODULE   md.tower  pl.C2_2   bc       60    0   60  YZ
MODULE   md.tower  BASE  pl.T1  bc-           ← 기준점 = T1 판 bc의 − 면

#ASSY   ID        ref MOD/ASSY  G.X  G.Y  G.Z  ROT.X ROT.Y ROT.Z
ASSY    as.comb   md.tower        0    0    0                    ← 모듈 통째로 배치
ASSY    as.comb2  md.tower      800    0    0     0    45     0  ← 같은 모듈, Y축 45° 회전
ASSY    as.big    as.comb         0    0  900                    ← 조립체를 다시 조립
ASSY    as.plate  pl.T1        -700    0    0                    ← 낱장 판도 배치 가능
```
(블록 방식 — `MODULE ID` 한 줄 후 `POS`/`BASE` 행 나열 — 도 계속 인식됨)

- 좌표 배치 예 (같은 `MODULE` 키워드, PLANE 자리에 숫자가 오면 좌표 방식):
```
#SECT    ID       MAT    Length  TYPE  BASE.pt  v1  v2  v3  v4  v5  v6
SECT     sc.brc   SS275    6000  L     bc       65  65   6   6   8   4   ← 6000은 정척, 참고값

#MODULE  ID       member      Ref.Pt  LX1  LY1  LZ1   LX2  LY2  LZ2  OFF_B  OFF_E  Alpha
MODULE   md.bay   sc.brc_1    (빈칸)    0  -60    0  2400  -60 3000     90     90
MODULE   md.bay   sc.brc_2    (빈칸) 2400   60    0     0   60 3000     90     90
MODULE   md.bay   sc.str_1    (빈칸)    0    0 1500  2400    0 1500    110    110     90
MODULE   md.bay   BASE  sc.brc_1  bc
```
브레이스 2개는 절점 사이 3841.9 에서 양끝 90 씩 물러나 **3661.9** 로 만들어지고,
스트럿은 기둥 플랜지를 피해 양끝 110 물러난 **2180**, `Alpha 90` 으로 채널이 위를 향한다.
세 부재 모두 정의는 단 두 줄(`sc.brc`, `sc.str`)뿐이다.

## 5. 처리 파이프라인

```
엑셀(.xlsx: PLATE/CUT/ASSY 3시트)
  → ExcelJS 로 로드 (기존 excel_reader.js 의 loadSheetData 방식)
  → PLATE+CUT: 외곽 폴리곤 − 빼기 폴리곤 → THREE.Shape → Extrude
  → ASSY: PLANE 행은 직접 변환행렬, EDGE 행은 대상 변의 월드좌표에서 유도
           (위→아래 1-pass, EDGE의 TO는 앞선 행만 참조 → 순환 방지)
  → BOM/중량 자동 집계, STL 내보내기
```

- 뷰어 HTML에 .xlsx 드래그&드롭 → 즉시 재생성 ("엑셀 수정 → 다시 드롭" 업데이트 흐름)
- 향후 확장: POLY(꼭짓점 나열) 형상, 경사 부재용 2점 구속, 그룹 단위 복제/이동
