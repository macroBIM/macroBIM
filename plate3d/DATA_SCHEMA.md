# plate3d 엑셀 데이터 입력체계 설계안 (v0)

플레이트 조립 모델을 엑셀로 데이터화하기 위한 시트 구조.
개념: **부재 정의(PLATE) → 빼기 형상(CUT) → 배치(PLACE)** 3시트.
구멍·노치가 있는 판은 "가장 큰 외곽 형상 + 내부/모서리 subtract" 조합으로 입력한다.

---

## 0. 기본 규약

### 형상 원형(primitive): 사다리꼴 TRAP
파라미터 4개로 삼각형·사각형·사다리꼴을 모두 표현한다.

```
      OF    TW
      ├──┤├────────┤
      P4──────────P3     ─┬─
     /              \     │ H
    /                \    │
   P1────────────────P2  ─┴─
   ├────────  B ───────┤
```

| 파라미터 | 의미 | 비고 |
|---|---|---|
| B  | 밑변 길이 | |
| TW | 윗변 길이 | TW = B → 직사각형, TW = 0 → 삼각형 |
| H  | 높이 | |
| OF | 윗변 좌측단의 수평 오프셋 | 생략 시 (B−TW)/2 = 등변 사다리꼴 |
| THK | 두께 | |

- 원형 판이 필요하면 SHAPE=CIRC, 파라미터 D(직경)만 사용.
- 로컬 좌표: P1 = (0,0) 원점, P1→P2 방향이 로컬 +x, 높이 방향이 로컬 +y, 두께가 로컬 +z.

### 부재의 표준 점 이름 (배치·정합에 사용)
| 이름 | 위치 |
|---|---|
| P1 P2 P3 P4 | 꼭짓점 (반시계, P1=좌하) |
| M12 M23 M34 M41 | 각 변의 중점 |
| C | 도심(centroid) |

두께 방향 면 구분이 필요하면 점 이름 뒤에 `+`(윗면/앞면), `-`(아랫면/뒷면)를 붙인다. 예: `P1-`, `C+`. 무표기 = 두께 중심.

### 기본 자세와 회전
**기본 자세(회전 0,0,0) = 정면도에 그린 그대로** — 로컬 x→월드 X(우), 로컬 y→월드 Y(상), 두께→월드 +Z(앞).
도면 치수를 그대로 입력하면 정면 수직판이 된다.

| 자세 | RX | RY | RZ |
|---|---|---|---|
| 정면 수직판 | 0 | 0 | 0 |
| 측면 수직판 (법선 X) | 0 | 90 | 0 |
| 수평판 (바닥/천장) | −90 | 0 | 0 |

회전 적용 순서: **RZ(면내 회전) → RX → RY**, 단위 도(°).
좌우 반전 부재(2EA 대칭품)는 MIRROR=X 로 처리.

## 1. PLATE 시트 — 부재 정의 (부품 라이브러리)

| ID | NAME | SHAPE | B | TW | H | OF | D | THK | MAT | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|
| C1 | 기둥판 | TRAP | 100 | 100 | 300 | 0 | | 10 | SS275 | |
| T1 | 상판 | TRAP | 350 | 350 | 300 | 0 | | 10 | SS275 | 레벨볼트 |
| S1 | 측판 | TRAP | 290 | 290 | 280 | 0 | | 10 | SS275 | 노치는 CUT |
| B1 | 우측판 | TRAP | 240 | 240 | 280 | 0 | | 10 | SS275 | |
| GUS1 | 거셋 | TRAP | 200 | 0 | 150 | 0 | | 10 | SS275 | 삼각형 예 |
| PAD1 | 패드 | CIRC | | | | | 80 | 10 | SS275 | 원판 예 |

- 수량은 여기에 쓰지 않는다 — PLACE 행 수에서 자동 집계.
- 같은 외곽이라도 구멍이 다르면 다른 ID (제작 도면과 동일한 원칙).

## 2. CUT 시트 — 빼기 형상 (구멍·노치·절단)

부재 ID에 귀속 (그 부재의 모든 배치 인스턴스에 공통 적용).
위치 (U,V)는 **부재 로컬좌표, P1 기준**.

| PLATE | TYPE | D | B | TW | H | OF | U | V | ANG | NX | PX | NY | PY | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| T1 | CIRC | 22 | | | | | 90 | 40 | | 2 | 220 | 2 | 220 | 레벨볼트 4-Ø22 |
| B1 | CIRC | 30 | | | | | 120 | 125 | | | | | | 핀 구멍 |
| S1 | TRAP | | 50 | 50 | 110 | 0 | 0 | 0 | | | | | | 좌하단 노치 |
| T2 | CIRC | 24 | | | | | 30 | 30 | | 2 | 200 | 2 | 180 | 앵커 4-Ø24 |

- **TYPE**: CIRC(원형, 중심=U,V) / TRAP(사다리꼴, 그 형상의 P1=U,V, ANG=면내 회전) / REF(다른 PLATE ID의 외곽을 빼기 형상으로 차용 — REF열에 ID 기입)
- **NX, PX / NY, PY**: 배열 복제 (개수, 피치). 볼트 구멍 패턴용. 생략 = 1개.
- 빼기 형상이 외곽선에 걸치거나 밖으로 나가면 자동으로 **노치/절단**이 된다 (S1 예).
- 겹치는 CUT 여러 개 → 순서대로 계속 subtract (복잡한 개구부 조합 가능).

## 3. PLACE 시트 — 배치 (인스턴스)

| NO | PLATE | ANCHOR | REF | X | Y | Z | RX | RY | RZ | MIRROR | GROUP | 비고 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| T2-1 | T2 | P1 | | −125 | 10 | 120 | −90 | | | | BOX | 하판 |
| S1-1 | S1 | P1 | | −145 | 0 | 130 | | | | | BOX | 전면 측판 |
| S1-2 | S1 | P1 | | −145 | 0 | −120 | | | | X | BOX | 후면 측판 |
| B1-1 | B1 | P1 | S1-1.P2- | | | | | 90 | | | BOX | 점 스냅 배치 |
| T1-1 | T1 | C | | 0 | 285 | 0 | −90 | | | | BOX | 상판(도심 기준) |
| C2-1 | C2 | M12 | T1-1.C+ | −55 | 0 | 0 | | 90 | | | COL | 상판 위 기둥판 |

- **ANCHOR**: 이 부재의 어느 점을 잡을지 (기본 P1).
- **REF**: 비우면 X,Y,Z는 **월드 절대좌표**. `인스턴스ID.점이름` 을 쓰면 그 점의 월드좌표에 앵커를 스냅하고 X,Y,Z는 **추가 오프셋**이 된다. → "포인트를 정확히 일치"시키는 입력 방법. 면 접촉은 `+`/`-` 면 지정으로 두께까지 정합.
- **모서리(변) 일치**: v0는 점 스냅 + 회전각으로 처리. v1에서 REF2(두 번째 참조점) 열을 추가해 "앵커→P2 방향을 REF2로 조준"하는 2점 구속을 지원 예정 (경사 부재도 각도 계산 없이 배치 가능).
- **GROUP**: 용접/조립 단위 병합. 뷰어에서 그룹 토글·색상, STL 내보내기 시 그룹별 solid, 중량 그룹 집계. 기하학적 union은 시각화에선 불필요하므로 v0는 논리적 병합만.

## 4. 처리 파이프라인

```
엑셀(.xlsx: PLATE/CUT/PLACE 3시트)
  → ExcelJS 로 로드 (기존 excel_reader.js 의 loadSheetData 방식과 동일)
  → PLATE+CUT: 외곽 폴리곤 − 빼기 폴리곤 (polygon boolean) → THREE.Shape → Extrude
  → PLACE: 앵커·REF 점 해석(의존 순서대로) → 회전·이동 행렬 → 씬 배치
  → BOM/중량 자동 집계, STL 내보내기
```

- 뷰어 HTML에 파일 드래그&드롭(또는 파일 선택)으로 .xlsx를 올리면 즉시 재생성 → "엑셀 수정 → 새로고침 없이 업데이트" 흐름.
- REF 는 앞선 행만 참조 가능(위→아래 1-pass 해석). 순환 참조 방지.
- CIRC 구멍은 Shape.holes, 외곽에 걸친 TRAP 절단은 폴리곤 클리핑으로 처리.
